# Inizia qui

Questo progetto e una biblioteca operativa di procedure e competenze per lavorare con Codex su codice, sistemi, IA, siti, applicazioni e progettazione grafica.

Non devi ricordare i codici `ARI`. Devi descrivere cosa vuoi fare.

## Uso rapido

Scrivi una richiesta normale:

```text
Analizza questo progetto e proponi migliorie.
```

Oppure:

```text
Crea una app Windows con interfaccia stile iOS/macOS.
```

Poi usa l'instradamento:

```text
START_HERE.md -> AGENTI.md -> CATALOGO.md -> Procedure/ARI-XXXX/
```

## Cosa usare

```text
Analisi progetto, diagnosi, piano              -> Agente Nucleo
Codice, bug, funzionalita, rifattorizzazione   -> Agente Codice
Git, Docker, Windows, Linux                    -> Agente Sistema
Modelli IA locali, agenti e prompt             -> Agente IA
Documentazione, manuali, glossario, testi      -> Agente Documentazione
Automazioni e flussi locali                    -> Agente Automazione
Pulizia, backup, inventario, ripristino        -> Agente Gestione Locale
App desktop Windows e installatori             -> Agente Desktop Windows
Siti, applicazioni, grafica, risorse, repliche -> Agente Web/App/Grafica
Sicurezza, segreti, privacy, licenze           -> Agente Sicurezza
Browser, prove interfaccia, schermate adattive -> Agente Browser/Test
Rilascio, pacchetti, pubblicazione             -> Agente Rilascio
Test, evidenze, validazione procedure          -> Agente Verifica
```

## Esempi pratici

```text
Analizza questo repository.
```


```text
Controlla Docker e perche il servizio non parte.
```

Usa `Agente Sistema`.

```text
Confronta questi modelli IA locali sul mio PC.
```

Usa `Agente IA`.

```text
Scrivi il manuale utente locale del progetto.
```

Usa `Agente Documentazione`.

```text
Correggi questo testo e rendilo piu tecnico.
```

Usa `Agente Documentazione`.

```text
Crea un prompt per un agente che revisiona siti web.
```

Usa `Agente IA`.

```text
Crea uno script PowerShell ripetibile per questa operazione.
```

Usa `Agente Automazione`.

```text
Fai inventario del progetto e prepara un backup locale.
```

Usa `Agente Gestione Locale`.

```text
Crea una pagina promozionale moderna con stile iOS/macOS.
```

Usa `Agente Web/App/Grafica`.

```text
Trova font, icone e immagini migliori per questo brand.
```

Usa `Agente Web/App/Grafica`.

```text
Rifai questo sito come replica funzionale legale, senza copiare asset.
```

Usa `Agente Web/App/Grafica`.

```text
Confeziona questa app come programma Windows installabile.
```

Usa `Agente Desktop Windows`.

```text
Controlla segreti, privacy, licenze e dipendenze.
```

Usa `Agente Sicurezza`.

```text
Automatizza il browser e verifica le schermate responsive.
```

Usa `Agente Browser/Test`.

```text
Prepara il rilascio e dimmi cosa manca.
```

Usa `Agente Rilascio`.

```text
Verifica se le procedure e le competenze sono coerenti.
```

Usa `Agente Verifica`.

## File principali

- `AGENTI.md` = instradamento completo dei macro-agenti
- `CATALOGO.md` = elenco ufficiale procedure
- `Procedure/` = procedure operative complete
- `Verifiche/` = evidenze e prove operative
- `Strumenti/` = validatori automatici

## Regola finale

Parti sempre dalla richiesta in linguaggio naturale. Il numero `ARI` serve solo per catalogare e recuperare il metodo giusto.
