# Revisione JavaScript e TypeScript

Segui integralmente la procedura descritta in `PROCEDURA.md` nella stessa cartella.

## Comportamento obbligatorio

- Identifica runtime, gestore pacchetti, framework e ambienti previsti.
- Verifica installazione deterministica, lint, tipi, test e build.
- Controlla ESM/CommonJS, validazione a runtime, errori, rete e variabili d'ambiente.
- Distingui chiaramente rischi client e server.
- Valuta dipendenze e riproducibilità della build con evidenze concrete.
- Produci il piano senza modificare il codice durante la revisione.
