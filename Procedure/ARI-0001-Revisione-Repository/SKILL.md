# Revisione repository

Segui integralmente la procedura descritta in `PROCEDURA.md` nella stessa cartella.

## Comportamento obbligatorio

- Analizza prima di modificare.
- Esegui build e test quando possibile.
- Cita evidenze concrete.
- Classifica i problemi da P0 a P4.
- Produci un piano di miglioramento.
- Non applicare modifiche finché il piano non viene approvato.
