# Revisione Git

Segui integralmente la procedura descritta in `PROCEDURA.md` nella stessa cartella.

## Comportamento obbligatorio

- Verifica ramo predefinito, working tree e regole di esclusione.
- Analizza cronologia, commit, tag e strategia dei rami.
- Cerca artefatti, file pesanti e possibili segreti senza esporli nel rapporto.
- Controlla protezioni del ramo principale e verifiche obbligatorie quando disponibili.
- Distingui anomalie reali da preferenze stilistiche.
- Produci un piano ordinato per rischio.
