# App Windows con interfaccia stile iOS/macOS

Segui integralmente la procedura descritta in `PROCEDURA.md` nella stessa cartella.

## Comportamento obbligatorio

- Distingui app Windows con stile iOS/macOS da app iOS nativa.
- Adatta il design a mouse, tastiera, hover, focus, ridimensionamento e DPI scaling.
- Valuta stack realistici: Electron, Tauri, Flutter, .NET MAUI, WinUI, WPF o Qt.
- Evita copie indistinguibili di brand, icone o componenti proprietari.
- Includi confezionamento, avvio, memoria e aggiornamento nella valutazione.
