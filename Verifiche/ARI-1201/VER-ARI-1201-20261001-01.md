## Ambito

Progettazione ed esecuzione di un'automazione PowerShell che rende consultabile offline il testo completo di README.md in un documento HTML UTF-8. Una sola invocazione operativa; nessun inventario, backup/restore di progetto, sintesi audio o test della CLI precedente. Criteri definiti prima del test nello script: destinazione nuova, contenuto protetto con HtmlEncode, equivalenza esatta dopo rilettura e HtmlDecode, hash sorgente invariato.

## Ambiente e accesso

Windows, PowerShell 7.6.5 già disponibile, API .NET integrate. Solo lettura README e creazione di file nuovi nella directory di supporto. Nessuna rete, installazione o modifica a componenti/configurazioni. Sorgente SHA-256 3EDB468581D3A7189249512BE63D9FCFEC7584A17B43DCEDC101AD60F8DAD69A. Snapshot di script, risultati e HTML disponibile in `../Supporto-ARI-1201-20261001/snapshot.json`.

## Passi esercitati

1. Definiti obiettivo e perimetro: anteprima offline del README senza modificare il testo.
2. Rilevati contenuto UTF-8 e hash sorgente.
3. Classificati rischi: overwrite, encoding e interpretazione HTML del testo. Contromisure: CreateNew, UTF-8 rigoroso, HtmlEncode e nessuna risorsa esterna. Nessuna dichiarazione di audit dei segreti nel README.
4. Creato script con parametri espliciti, errori bloccanti e lettura tramite percorsi letterali.
5. Eseguito una sola volta: `anteprima.ps1 -Sorgente <README.md assoluto> -Destinazione <README-anteprima.html assoluto>`.
6. Riletto output, confrontato il testo decodificato carattere per carattere e verificato hash originale.
7. Registrati risultati, hash, ambiente e limiti.
