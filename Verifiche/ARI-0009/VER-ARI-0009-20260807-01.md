## Rilievi prodotti

### AIA-TST-001 — Percorsi negativi dei validatori canonici non testati con fixture dedicate

- **Categoria:** comportamento critico non coperto
- **Priorità:** P2
- **Area:** `Strumenti/verifica_procedure.py`, `Strumenti/verifica_skills.py`
- **Evidenza:** la CI prova che il repository valido viene accettato; gli unittest presenti coprono evidenze e promozioni, non strutture `PROCEDURA.md`/`SKILL.md` volutamente invalide.
- **Impatto:** una regressione che rendesse uno dei validatori troppo permissivo potrebbe non emergere se il repository corrente resta ben formato.
- **Test proposto:** fixture temporanee con titolo ARI errato, sezione obbligatoria mancante/vuota, front matter skill mancante, `name` duplicato e mancato riferimento a `PROCEDURA.md`; risultato atteso: exit code non zero e messaggio specifico.

### AIA-TST-002 — Smoke test installatori verifica il conteggio ma non la parità dei contenuti

- **Categoria:** test debole
- **Priorità:** P3
- **Area:** `.github/workflows/verifica-arsenale.yml`
- **Evidenza:** dopo l'installazione viene contato il numero di directory e confrontato con 19.
- **Impatto:** un errore di copia che materializzasse file errati ma mantenesse 19 directory potrebbe sfuggire al controllo finale.
- **Test proposto:** per ogni skill installata verificare presenza di `SKILL.md` e `PROCEDURA.md`, corrispondenza del nome runtime e hash/contenuto rispetto alla sorgente prevista.

### AIA-TST-003 — Un test mescola unità e stato reale del repository

- **Categoria:** test troppo accoppiato al contesto
- **Priorità:** P4
- **Area:** `test_real_procedure_accepts_declared_history_only`
- **Evidenza:** il test legge la cronologia reale di ARI-0001 e assume la presenza di versioni specifiche.
- **Impatto:** è utile come piccolo test di integrazione, ma può fallire per evoluzione documentale anziché per difetto della funzione pura.
- **Test proposto:** mantenere eventualmente il controllo d'integrazione ma aggiungere una fixture sintetica per testare separatamente il parser della cronologia.
