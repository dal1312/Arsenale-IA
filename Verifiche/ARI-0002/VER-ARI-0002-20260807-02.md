## Rilievi prodotti

### OFL-CR-001 — Test di regressione troppo legato al testo del sorgente

- **Gravità:** Media
- **File e funzione:** `tests/unit/test_release_gate_workflow.py` — `test_final_release_check_manages_validation_redis_in_github_actions()`
- **Evidenza:** il test usa `read_text()`, ricerca marker e confronti con `text.index()`; non esercita il comportamento delle funzioni Redis aggiunte.
- **Impatto:** la suite può restare verde se le stesse stringhe rimangono nel file ma un refactoring o un errore rompe argomenti `docker`, gestione dei return code, timeout o cleanup. Il release gate reale dimostra il percorso positivo post-merge, ma non sostituisce test unitari dei rami negativi.
- **Correzione consigliata:** aggiungere test comportamentali con monkeypatch/mock di ambiente, `_redis_ping`, `subprocess.run` e `time.sleep` per i principali rami di decisione.
- **Test richiesto:** almeno no-op fuori da GitHub Actions; Redis già disponibile; start riuscito e cleanup; start fallito; timeout con rimozione del container.
