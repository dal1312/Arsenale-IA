# Copie pubblicabili delle evidenze

Questa preparazione editoriale non costituisce una nuova prova operativa. Stato, tipo Interna/Indipendente, risultati e hash attestati restano invariati.

Gli originali dei file modificati o esclusi sono conservati fuori dal repository nella directory di backup indicata nel rapporto di preparazione, con manifest contenente percorso originale, dimensione e SHA-256 verificato. Il manifest completo è locale e contiene dati personali.

Nei supporti redatti, il prefisso del profilo Windows è sostituito da `C:\Users\[UTENTE]`. I percorsi redatti non sono percorsi operativi. La copia di Genera-Audio.ps1 in Supporto-Audio è una testimonianza storica redatta, non lo script runtime; lo script corrente è in Strumenti.

Gli hash nei rapporti e negli snapshot continuano a identificare i file originali. La redazione modifica necessariamente i byte delle copie: non confrontare gli hash originali con una copia redatta né interpretarli come checksum della pubblicazione. Per verificare i byte originali occorre accedere al backup locale; tale accesso non è disponibile al lettore pubblico.

Sono esclusi backup, log temporanei, baseline diagnostiche, runner di campagne, output bin/obj, database temporanei, input.bin e copie runtime duplicate. Le evidenze canoniche, i risultati JSON e gli snapshot non diagnostici rimangono nel repository. I riferimenti ai supporti esclusi descrivono la prova storica; non garantiscono che il supporto sia scaricabile da GitHub.

I due file .env di ARI-2202 contengono esclusivamente credenziali FITTIZIO_* o valori [OMESSO], oltre alla porta del servizio di prova: sono fixture sintetiche, non configurazioni operative. Gli archivi gzip sono piccole fixture del test di compressione, non distribuzioni software.

Nessun audio è stato rigenerato. Nessun risultato o soglia di promozione è cambiato.
